# Remark

> Conversations for the open web.

Remark is a lightweight, open-source comments widget powered by GitHub Issues. It gives websites, blogs, and documentation a simple way to add threaded discussions without building or maintaining a separate backend.

## ✨ What we're building

- 💬 Simple, embeddable comments
- 🧵 Threaded conversations
- 👍 Reactions powered by GitHub
- 🛡️ Moderation through GitHub Issues
- ⚡ Fast, lightweight, and developer-friendly
- 🔓 Open source and community-driven

## 🚀 Get started

Add Remark to your website, connect it to a GitHub repository, and let your community start talking.
