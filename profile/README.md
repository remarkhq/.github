<p align="center"><strong>Conversations for the open web.</strong></p>

Remark is a lightweight, open-source comments widget powered by GitHub Issues. Add threaded discussions to your website, blog, or documentation without building or maintaining a separate commenting platform.

## Why Remark?

- 💬 **Simple, embeddable comments** for your website or documentation
- 🧵 **Threaded conversations** that keep discussions organized
- 👍 **GitHub-powered reactions** for familiar community engagement
- 🛡️ **Moderation through GitHub Issues**
- ⚡ **Fast and lightweight**, with a developer-friendly setup
- 🔓 **Open source and community-driven**

## Get started

Connect Remark to a GitHub repository and give your community a place to ask questions, share feedback, and start conversations.

[Explore Remark →](https://github.com/remarkhq/remark)
